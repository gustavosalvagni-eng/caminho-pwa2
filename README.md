# Caminho — PWA para celular

Versão mobile-first do aplicativo católico Caminho, independente do Django.

## Publicar no GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

URL prevista: https://gustavosalvagni-eng.github.io/caminho-pwa2/

## Instalar no iPhone
Abra a URL no Safari → Compartilhar → Adicionar à Tela de Início.

## Privacidade e limites
O diário é armazenado somente no localStorage do navegador, sem login, sincronização ou criptografia própria. Exporte cópias regularmente. O conteúdo público é disponibilizado offline por service worker. Esta versão é simplificada e não tem painel administrativo Django.
